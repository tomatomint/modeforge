ModeForge — Documentation

ModeForge adds a Dark mode to your existing Webflow variable collection. It generates Dark values from the color variables you already use, checks text/background contrast, and applies everything at once — after you download a backup.

Requirements

  • A Webflow site with at least one variable collection that contains color variables.
  • Designer access to edit that site.

Installation

  1. Install ModeForge from the Webflow Marketplace into your workspace.
  2. Open your site in the Webflow Designer.
  3. Open ModeForge from the Apps panel. The app runs entirely inside the Designer — there is no server and no separate account to create.

How to use

  1. Select — Pick a variable collection. ModeForge lists your color variables with their current swatches. Non-color variables are counted and left alone. If a Dark mode already exists, ModeForge updates it instead of creating a duplicate.
  2. Generate — Choose a preset (Standard, Darker, or Lighter). Nothing is written to your site at this point.
  3. Preview — A side-by-side table shows every variable's Light value next to its generated Dark value. Click any cell to fine-tune a single value by hand.
  4. Apply — ModeForge first prompts you to download a backup JSON of your original values, then creates the Dark mode and sets all values at once, and reports how many succeeded.

Contrast checking

ModeForge estimates background/text pairs from your variable names and computes their WCAG contrast ratio. If a pair falls below 4.5:1, it raises the text lightness step by step and recalculates, and flags the pair in the preview instead of silently changing your hue. Colors it cannot classify still get the standard conversion and are marked "role unknown" in the preview.

Backup and safety

  • Nothing is written until you press Apply, and the backup download comes first. Webflow's Designer API has no undo for variable writes, so the backup JSON is your safety net — keep it until you have checked the result.
  • To roll back, re-import your original values from the backup JSON by editing the variables, or delete the generated Dark mode.
  • No data leaves your site: the app runs entirely on the Designer API inside the Designer.

Limitations (v1)

  • One collection at a time (no multi-collection batch).
  • Color variables only — size, number, and font variables are out of scope.
  • No visitor-facing toggle code is embedded automatically; after applying, use Webflow's variable-mode switching for your site and follow the guidance shown in the app.
