Privacy Policy — ModeForge

Effective date: November 12, 2026
Contact: via the developer page on note (https://note.com/novel_mint2747)

Overview

ModeForge is an app that runs inside Webflow Designer. It helps users generate an additional color mode (for example, a Dark mode) from the color variables already defined in their Webflow site. ModeForge operates entirely within Webflow Designer.

Data we collect

ModeForge does not collect, store, or transmit personal data. It has no server, uses no analytics, and sets no cookies.

What ModeForge accesses

To do its work, ModeForge reads the values of color variables in the user's Webflow site and, only when the user instructs it to apply changes, writes new variable values back to that same site. Variable values are processed inside Webflow Designer and are not sent outside Webflow by ModeForge.

Data storage and transmission

ModeForge does not store user data on external servers and does not transmit site data, variable values, or personal data to the developer or to any third party.

Third parties

ModeForge does not share data with third parties, because it does not collect or transmit data as described above.

Changes to this policy

If this policy is updated, the revised version will be published at the same location as this policy, with a new effective date.
